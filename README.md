# RTI — Tier 2 Digital

App de celular (offline, sem login) para registrar a avaliação individual de leitura **Tier 2** do projeto RTI/MTSS:
lança as respostas dos 8 módulos, calcula tudo, preenche o *Resumo e Decisão*, sugere o perfil (árvore do Manual) e exporta Excel.

- App: pasta [`app/`](app/) — abra `app/index.html` pelo link do GitHub Pages.
- **Guia passo a passo:** [COMO_USAR.md](COMO_USAR.md)
- Dados dos alunos ficam **só no aparelho** (armazenamento local do navegador). Nada é enviado para a internet.
